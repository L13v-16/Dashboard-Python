# Dashboard-Python
MVP feito, com linguagem Python, para cadeira de Programação Orientada a Objetos. Um dashboard que acompanha as mudanças nos preços de hardwares, através do webscrapping de varejistas online.

## Instalação

1. Clone o repositório

```bash
git clone https://github.com/L13v-16/Dashboard-Python.git
cd Dashboard-Python
```

2. Crie um ambiente virtual

```bash
python -m venv .venv
```

3. Ative o ambiente virtual

Windows:

```bash
.venv\Scripts\activate
```

4. Instale as dependências

```bash
pip install -r requirements.txt
```
